# eJPT-NOTES

## eJPT (PTS) — Practical Notes, Commands & Methodology

This repository contains my personal notes, commands, methodologies, and practical
learnings from the **eLearnSecurity Junior Penetration Tester (eJPT)** path and
hands-on labs.

The notes are structured as a clean, reusable command reference built while working
through INE's **Penetration Testing Student (PTS)** course and lab practice.

---

## 🎯 Objective

Build a practical, exam-ready junior-pentester foundation through hands-on learning
and a repeatable testing methodology.

Key areas include:

- Information gathering & reconnaissance
- Footprinting, scanning & enumeration
- Vulnerability assessment
- Host & network penetration testing
- The Metasploit Framework
- Exploitation & post-exploitation
- Web application penetration testing

## 📂 Repository Structure

One folder per module, grouped by eJPT/PTS domain. Every module note follows the same
layout: goal, then clean reference sections — commands (labelled by machine where
relevant), techniques, and a fix/notes summary.

```
eJPT-NOTES/
├── cheatsheets/        ← command quick-reference, grouped by topic
├── templates/          ← note layout every module follows
└── (module folders added as each section is filed)
```

> No exam content, flags, or copied course material is published here — just my own
> notes, standard tooling commands, and methodology.
